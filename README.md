# টাইপ শিখি — বাংলা (বিজয়) ও ইংরেজি টাইপিং সফটওয়্যার

ব্রাউজারেই চলে এমন একটি টাইপিং টিউটর। কোনো ইনস্টল লাগে না, বিজয় সফটওয়্যারও লাগে না —
অ্যাপ নিজেই বিজয় লেআউটে কোন কী চাপতে হবে তা দেখায় ও যাচাই করে।

## কী কী আছে

- **পাঠ (১৫ + ১৫টি)** — হোম রো থেকে শুরু করে উপরের/নিচের সারি, Shift, যুক্তাক্ষর, সংখ্যা, বাক্য পর্যন্ত ধাপে ধাপে।
  প্রতিটি পাঠে ★ রেটিং (নির্ভুলতা ও গতি অনুযায়ী)।
- **অনুশীলন** — শব্দ, বাক্য, অনুচ্ছেদ, হিসাব-নিকাশ (ভাউচার, ভ্যাট, চালান, জাবেদা), সংখ্যা (লাখ-কোটি ফরম্যাট), আর নিজের লেখা পেস্ট করে অনুশীলন।
- **স্পিড টেস্ট** — ১, ২, ৩ বা ৫ মিনিট; WPM, নির্ভুলতা ও ভুলের হিসাব।
- **অন-স্ক্রিন কিবোর্ড** — পরের কী জ্বলে ওঠে, কোন আঙুল দিয়ে চাপবেন তা রঙে দেখায়; Shift লাগলে উল্টো হাতের Shift দেখায়।
- **বিজয় গাইড** — বিজয়ের নিয়ম (আগে কার, যুক্তাক্ষর g দিয়ে, রেফ Shift+A ইত্যাদি) আর একটি টুল: যেকোনো বাংলা শব্দ লিখলে বিজয়ে কোন কী কোন ক্রমে চাপতে হবে তা দেখায়।
- **অগ্রগতি** — সেরা গতি, গড় নির্ভুলতা, মোট অনুশীলনের সময়, যে কী-তে বেশি ভুল হয়, আর আগের সব সেশনের তালিকা।
- **দুই ধরনের ইনপুট**
  - *বিজয় (গাইডসহ)* — কম্পিউটারের কিবোর্ড ইংরেজিতে রেখে টাইপ করুন, অ্যাপ বিজয় লেআউটে বাংলা বানায়।
  - *নিজস্ব কিবোর্ড* — অভ্র, বিজয় সফটওয়্যার বা মোবাইলের বাংলা কিবোর্ড দিয়ে টাইপ করুন; লেখা মিলিয়ে দেখা হয়।

ফলাফল শুধু আপনার ব্রাউজারে (localStorage) সংরক্ষিত থাকে।

## কীভাবে চালাবেন

1. এই ফোল্ডারের `index.html` ফাইলটি ব্রাউজারে (Chrome/Edge/Firefox) খুলুন — ইন্টারনেট ছাড়াও চলবে
   (ইন্টারনেট থাকলে সুন্দর ফন্ট লোড হবে)।
2. অথবা GitHub Pages চালু করুন: রিপোজিটরির **Settings → Pages → Branch** থেকে ব্রাঞ্চ বেছে নিন,
   তাহলে একটি ওয়েব লিংক পাবেন যা অফিসের যেকোনো কম্পিউটার বা মোবাইলে খোলা যাবে।

## ফাইল

| ফাইল | কাজ |
| --- | --- |
| `index.html` | পেজের কাঠামো |
| `assets/style.css` | ডিজাইন (লাইট ও ডার্ক মোড) |
| `assets/bangla.js` | বিজয় ইঞ্জিন — বাংলা লেখাকে কী-চাপের ক্রমে রূপান্তর |
| `assets/content.js` | পাঠ, শব্দ, বাক্য, অনুচ্ছেদ ও হিসাবের লেখা |
| `assets/app.js` | টাইপিং, কিবোর্ড, ফলাফল ও অগ্রগতি |
| `tests/bijoy.test.js` | বিজয় ইঞ্জিনের টেস্ট (`node tests/bijoy.test.js`) |

নতুন বাক্য বা শব্দ যোগ করতে চাইলে `assets/content.js` ফাইলে লিখে দিন — বিজয়ের কী-ক্রম অ্যাপ নিজেই বের করে নেবে।
